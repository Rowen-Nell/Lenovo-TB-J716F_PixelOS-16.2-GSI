# Licensing and redistribution review

Source-only review candidate. Upstream copyright/NOTICE/license text is retained in sources, patch context and licenses/. Android manifest references retain their original licensing. New project glue is Apache-2.0. Device/phh charger images and audio policy retain their upstream source notices; the audio XML includes AOSP Apache-2.0 and Linux Foundation notices. No proprietary Google APK/DEX or OEM firmware is included in this source candidate.

The locally built system image contains Google/prebuilt/vendor project dependencies. Their public binary redistribution permissions have not been established by this build. The image is delivered separately for the existing device test; it is not included in the Git candidate or approved for a public Release. Before publishing a binary release, review the exact installed inventory and upstream proprietary file lists, retain required notices/source offers, and confirm independent custody of the already fixed project release keys. No private signing key is distributed here. The candidate uses project release authority j716f-beta-release-v1 for source-built APK/APEX/system AVB; unchanged PRESIGNED Google packages and the standard CTS shim are explicit exceptions.

This is an unofficial experimental device adaptation, not a claim of PixelOS/OEM/Google certification. Linux kernel source/device validation, SELinux Enforcing and encryption acceptance, GMS certification, installation/upgrade/rollback and hardware acceptance remain separate gates. The present system-only image retains the stock kernel/vendor baseline.
