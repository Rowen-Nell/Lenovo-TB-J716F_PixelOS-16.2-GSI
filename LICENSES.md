Public source and release licensing notes. Upstream copyright/NOTICE/license text is retained in sources, patch context and licenses/. Android manifest references retain their original licensing. New project glue is Apache-2.0. Device/phh charger images and audio policy retain their upstream source notices; the audio XML includes AOSP Apache-2.0 and Linux Foundation notices. No proprietary Google APK/DEX or OEM firmware is included in this source candidate.

The locally built system image contains Google/prebuilt/vendor project dependencies. Their public binary redistribution permissions have not been established by this build. The system image is provided separately as an unofficial test Beta asset, not as a Git source file. The public installed inventory and pinned upstream sources identify dependencies; neither this publication nor the project license grants new rights in proprietary dependencies. Maintainer key custody remains a separate recovery and future-upgrade responsibility. No private signing key is distributed here. The candidate uses project release authority j716f-beta-release-v1 for source-built APK/APEX/system AVB; unchanged PRESIGNED Google packages and the standard CTS shim are explicit exceptions.

This is an unofficial experimental device adaptation, not a claim of PixelOS/OEM/Google certification. Linux kernel source/device validation, SELinux Enforcing and full encryption/security acceptance remain unfinished final-product gates; Enforcing is paused for the first permissive test Beta. GMS certification, upgrade/rollback and full hardware acceptance remain separate. The paired release retains stock vendor plus a one-byte patched stock precompiled kernel; it is not a source-built kernel.

The paired charging boot and exact stock rollback boot remain external large OEM binaries, not source-repository files. A one-byte Python patch script is not the matching Linux source code and does not by itself settle kernel GPL/source-offer or OEM redistribution obligations. Review the applicable exact binary provenance, corresponding-source/source-offer requirements and notices before a public binary release. Existing local full image hashes are references, not redistribution grants. No private keys are provided or regenerated here.
